# Randevu Frontend Implementation Plan

> **For agentic workers:** Implement task-by-task.

**Goal:** Fresha-inspired Turkish marketplace SPA wired to randevu backend.

**Architecture:** Feature-based Vite React SPA; React Query for server state; Zustand for auth.

**Tech Stack:** Vite, React 19, TypeScript, React Router 7, Tailwind 4, TanStack Query, Zustand
